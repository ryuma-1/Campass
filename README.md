# Campass

独学における「次に何を学べばいいかわからない」「基礎ばかりで飽きてしまう」という課題を解決するための学習支援システムです。LLM（生成AI）を活用し、ユーザーの最終ゴールから逆算した「トップダウン逆算型ボトムアップ学習」のプロセスを動的に生成・提示します。

表面的なハウツーにとどまらず、技術の裏側にある原理・原則を深く理解したい独学者をターゲットとしています。

---

## 🎯 プロジェクトの目的とゴール

* **独学の挫折解消:** 迷子にならない一本道のパーソナライズされた学習ロードマップを提供します。
* **本質的な理解の支援:** 目的意識を持った学習者が、背景や原理原則まで深くステップアップできるカリキュラムを生成します。
* **認知負荷の最小化:** 複雑な学習ネットワーク構造をリニア（一本道）に変換し、ユーザーが「今やるべきこと」に集中できるUIを提供します。

---

## ✨ 主な機能

本システムは以下の主要機能を備えています。

| 機能カテゴリ | 機能名 | 概要 |
| :--- | :--- | :--- |
| **初期入力** | ゴール提案と深さ選択 | 曖昧な入力に対するAIからのゴール提案と、3段階の学習深度（難易度）選択機能。 |
| **初期入力** | 前提知識アセスメント | 簡易クイズや自己申告による既習知識のスキップと最短プロセスの構築。 |
| **AI連携** | シラバスの動的生成 | プロンプトの制約条件に従い、LLMが構造化されたシラバス（JSON）を生成。 |
| **マップ表示** | リニア変換とドリルダウン | 複雑な構造を一本道で提示し、クリックで細かい前提知識を展開（折りたたみ）。 |
| **学習管理** | ノートブック機能 | 複数の学習テーマを並行管理できる独立した作業スペースの作成・保持。 |

---

## 🛠 技術スタック

当プロジェクトのシステム構成は以下の通りです。

* **フロントエンド:** React / Next.js
* **バックエンド:** Node.js (TypeScript)
* **データベース:** PostgreSQL
* **インフラストラクチャ:** AWS (ECS, RDS, S3)
* **外部API:** LLM API (ChatGPT, Claude, Gemini等のいずれかを利用)
